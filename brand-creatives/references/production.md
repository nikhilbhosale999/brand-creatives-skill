# Produce and revise artwork

## Resolve the brief

Use the requested channel, format, dimensions, language, audience, offer, CTA and supplied copy. Reuse approved brand choices and any established output defaults. For an unspecified social post, use 1080 × 1350 px as a working size and report it. For print, use the requested physical size and page or panel count. When essential facts are missing, produce what can be reviewed with clearly marked placeholders or omitted optional copy. Flag any open facts that prevent a final export.

## Compose the design

Read the guide and palette, inspect the actual logo and relevant product or style assets, and check that font files or approved fallbacks are available. Place the actual logo, exact copy and legal text in editable composition layers. Use image generation when available and useful for original artwork. Use supplied photos, native shapes and typography to create the layout when working with local tools. Preserve logo proportions, approved variants and product fidelity. Label artwork that uses proposed identity choices as a draft.

Fit the composition to the medium. Social formats need mobile-legible hierarchy and sensible margins. Posters need a readable headline and CTA at their intended viewing distance. Print pamphlets also need checks for page order, fold positions, panel widths and margins. Check the actual delivery specs when the user requests a platform-specific or print-ready export. Verify bleed, resolution, color profile and PDF requirements against any supplied print specifications before describing a file as print-ready.

## Save and verify

- Use a new campaign directory under `brand/outputs/` or the documented project output folder. Save the individual exports and available editable sources there. Keep prior outputs when creating revisions.
- For a batch of options, label the actual designs with stable numbers in filenames or a preview, and use clearly different compositions. Keep numbering off clean exports. Add a short production record with the brief, asset sources, dimensions, copy, individual file and editable source for each option, and any selected revision. This lets a later chat recover “option 2” from files.
- When finishing a selection, re-render its original design at the requested size and change only the requested details. Check assets and native resolution before promising a higher-quality export.
- Open or render each export and inspect it at delivery size, checking text, alignment, contrast, safe margins, logo and assets, and print panels where relevant. Confirm file encoding, page count or pixel dimensions, and any required links or QR targets. Report the actual files, formats and dimensions. Label drafts and unresolved export requirements plainly.
