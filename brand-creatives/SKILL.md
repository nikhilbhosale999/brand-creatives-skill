# Brand Creatives

Use the business's brand kit from the project the user opened or named. Treat that project root as the scope for discovery and all writes. Resolve an explicit brand or path inside the project first. Otherwise start with root `brand.md`, then check for a clearly identifiable guide such as `brand/brand.md`. If multiple brands fit and the target is unclear, ask which brand to use. Copy assets from other locations only when the user supplies them for this project.

| Request | Workflow |
| --- | --- |
| Onboard or update a brand | Read [onboarding](references/onboarding.md). Use the supplied guide, assets, website, or business brief. |
| Create or revise artwork | Read the existing guide and linked palette and assets, then follow [production](references/production.md). An existing guide is enough to start. |
| Create artwork when the project has no brand guide | Onboard from available project material and the user's brief, then continue the creative task. If no brand identity can be established, ask for its name and what it does. |

Use the user's current instructions for the current job. Save changes to the brand kit when the user requests an update or approves a proposed identity. For revisions and numbered selections, recover the individual design and editable source from the relevant project output folder.
